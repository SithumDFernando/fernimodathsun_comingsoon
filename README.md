# fernimodathsun.design

Minimalist "Launching Soon" landing page for [fernimodathsun.design](https://fernimodathsun.design) featuring an interactive animated scorpion centerpiece with a yellow, orange, and obsidian black theme.

## Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Vanilla CSS (SVG animation & 3D tilt)
- **Effects**: HTML5 Canvas dynamic ember particles

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
